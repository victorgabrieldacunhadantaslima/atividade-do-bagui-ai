# Atividade API Produtos

## Descrição

Projeto desenvolvido para criar uma API com Node.js e Express e um frontend utilizando HTML, CSS e JavaScript.

O frontend utiliza Fetch para buscar os dados disponibilizados pela API e apresentar as informações do produto na página.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- Node.js
- Express
- CORS
